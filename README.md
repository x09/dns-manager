# Диспетчер DNS для Samba DC

Графическая утилита для GNU/Linux — аналог **Microsoft DNS Manager**.
Подключается к DNS-серверу, встроенному в контроллер домена **Samba DC**,
по протоколу MS-DNSP (DCERPC).

## Новое в версии 4.0

- **Консольная (TUI) версия — `dns-manager-tui`.** Отдельное приложение
  с тем же функционалом, работает в терминале и по SSH (без X-сервера).
  Интерфейс в стиле Midnight Commander: слева дерево серверов/зон/папок,
  справа записи, внизу статусная строка и подсказка F-клавиш.
  Построен на библиотеке **urwid** (в ОС Альт — пакет
  `python3-module-urwid`); пакет `dnsmgr` общий для GUI и TUI
  (backend, Kerberos, конфиг и переводы переиспользуются без изменений).

  Клавиши:

  | Клавиша | Действие |
  |---|---|
  | `Tab` | переключение между панелями |
  | `Enter` | раскрыть узел / открыть зону; в правой панели — правка записи |
  | `Ins` / `Space` | пометить/снять пометку записи (для группового удаления) |
  | `F2` | подключиться к серверу |
  | `F4` | изменить запись |
  | `F5` | обновить |
  | `F6` | экспорт в CSV (помеченные записи или вся зона) |
  | `F7` | создать зону (левая панель) / запись (правая) |
  | `F8` / `Del` | удалить зону (левая) / помеченные записи (правая) |
  | `F9` | меню (отключение, язык интерфейса, о программе) |
  | `F10` / `q` | выход |

  Групповое удаление: пометьте записи `Ins` (звёздочка слева, как в MC),
  затем `F8` — появится список подтверждения. Записи NS/SOA и папки
  не помечаются и пропускаются, как в GUI.

  Ширина левой панели настраивается через конфигурационный файл
  `~/.config/dns-manager/dns-manager.ini`, секция `[settings]`:
  ```ini
  [settings]
  tui_left_width = 34    ; ширина левой панели в колонках (16…120)
  ```

  Запуск: `./dns-manager-tui.py` (нужны `python3-module-urwid` и
  `python3-module-samba`; tkinter НЕ требуется).

## Новое в версии 3.6

- **Экспорт записей в CSV (аналог «Export List» из MS DNS Manager).**
  По правому клику на зоне в левом дереве — пункт **«Экспортировать список»**
  сохраняет всю зону рекурсивно (включая служебные папки `_sites`, `_tcp`,
  `DomainDnsZones` и т.д.) в CSV-файл с разделителем-табуляцией. Также можно
  выделить отдельные записи в правой панели (Shift/Ctrl) и экспортировать
  только их через тот же пункт в контекстном меню. Типы записей выводятся
  в стиле MS DNS Manager (`Host (A)`, `Alias (CNAME)`, `Mail Exchanger (MX)`,
  `Start of Authority (SOA)` и т.д.), `@` заменяется на
  `[Same as parent folder]`, первая строка — заголовок. Файл сохраняется
  в кодировке UTF-8 (с BOM) для корректного открытия в Excel.
- **Кликабельная ссылка в окне «О программе».** Адрес сайта проекта
  отображается ссылкой и открывается в браузере по умолчанию (используется `xdg-open`).

## Новое в версии 3.5

- Добавлено множественное удаление записей.Правая панель записей теперь поддерживает Shift (диапазон) и Ctrl (отдельные записи).
- Групповое удаление с фильтрацией. При удалении из выбора автоматически отбрасываются папки и нередактируемые записи (`NS`, `SOA`) — удаляются только обычные записи.

## Новое в версии 3.4

- **Мультиязычный интерфейс (русский / английский).** Локализация
  выполнена на базе стандартного механизма `gettext` (файлы `.po`/`.mo`)
  по модели с ключами (key-based): в коде используются нейтральные
  семантические идентификаторы (`menu.new_zone`, `dlg.server.title`,
  `err.bad_ipv4` и т.п.), а каждый язык — отдельный каталог перевода.
  Код не привязан к какому-либо языку.

  - При первом запуске язык определяется по локали ОС; если это не
    русская и не английская локаль (или определить не удалось) —
    выбирается английский.
  - Выбранный язык сохраняется в `~/.config/dns-manager/dns-manager.ini`
    в секции `[settings]` (`language = ru|en`).
  - Переключатель — в меню **Справка → Язык интерфейса**. После смены
    языка приложение предлагает перезапуститься (изменения применяются
    при следующем запуске).
  
  Каталоги переводов ищутся в нескольких местах по порядку:
  
  - переменная окружения `DNSMGR_LOCALEDIR` (если задана);
  - рядом с пакетом — `dnsmgr/locale/` (запуск из исходников);
  - системный `/usr/share/locale/` (установка в дистрибутив).

  Используется первый найденный. Имя `.mo` в любом месте — по имени
  домена: `<язык>/LC_MESSAGES/dnsmgr.mo`. Например, при установке в
  систему переводы можно положить в стандартное место gettext:
  ```
  /usr/share/locale/ru/LC_MESSAGES/dnsmgr.mo
  /usr/share/locale/en/LC_MESSAGES/dnsmgr.mo
  ```
  а при запуске из папки проекта используется встроенный `dnsmgr/locale/`:
  ```
  dnsmgr/locale/ru/LC_MESSAGES/dnsmgr.{po,mo}   # русский
  dnsmgr/locale/en/LC_MESSAGES/dnsmgr.{po,mo}   # английский
  ```
  Оба языка равноправны. Если каталог выбранного языка не найден нигде,
  в интерфейсе будут видны сами ключи.

## Новое в версии 3.2

- **Пиктограммы записей в правой панели.** Три вида: обычная запись
  (A, AAAA, CNAME, MX, PTR, SRV, TXT) — документ с текстом; папка
  (вложенный раздел зоны) — жёлтая папка; запись «только чтение»
  (NS, SOA — управляются сервером) — серый документ с замком.
- **Имя сервера в дереве выделено жирным шрифтом.**

## Новое в версии 3.0

- **Kerberos / GSSAPI.** При наличии действующего TGT (билета Kerberos)
  в диалоге подключения появляется флажок «Использовать данные Kerberos
  для входа». При включении пароль не запрашивается — подключение
  выполняется через GSSAPI с имеющимся билетом. Билет определяется
  командой `klist`; поддерживаются MIT krb5 и Heimdal.
  Если билета нет — флажок неактивен, используется обычный вход.

- **Несколько серверов одновременно.** Подключённые серверы отображаются
  в дереве слева как отдельные корневые узлы (как в MS DNS Manager).
  Кликом на другом сервере переключается активный; можно держать несколько
  серверов подключёнными параллельно.

- **Список серверов в конфиге.** После успешного подключения сервер
  сохраняется в `~/.config/dns-manager/dns-manager.ini`. При запуске
  сохранённые серверы показываются в диалоге выбора. Пароль по-прежнему
  не сохраняется.

  Формат файла:
  ```ini
  [192.168.1.10]
  user = Administrator
  kerberos = false

  [dc.corp.local]
  user = admin@CORP.LOCAL
  kerberos = true
  ```

- **Пиктограммы на панели инструментов.** Все кнопки (Подключиться,
  Обновить, Создать/Удалить зону, Создать/Изменить/Удалить запись)
  получили иконки 20×20 пикселей. Сгенерированы программно, без внешних
  зависимостей — лишних файлов не требуется.

## Возможности (из предыдущих версий)

- Просмотр, создание и удаление прямых и обратных зон (интегрированных в AD).
- Создание, изменение и удаление записей: **A, AAAA, CNAME, MX, PTR, SRV, TXT**.
- Автоматическое создание PTR-записи при добавлении A-записи.
- Служебные разделы зоны (`_sites`, `_tcp`, `DomainDnsZones`, `_msdcs` и т.д.)
  отображаются в дереве как папки с ленивой подгрузкой; записи доступны
  в любой папке.
- Записи NS и SOA показываются в режиме только чтения.

## Требования (ОС Альт)

```
# GUI-версия:
# apt-get install python3-modules-tkinter python3-module-samba
# TUI-версия:
# apt-get install python3-module-urwid python3-module-samba
```

## Запуск

```
chmod +x dns-manager.py dns-manager-tui.py   # один раз

./dns-manager.py       # графическая версия (tkinter)
./dns-manager-tui.py   # консольная версия (urwid), работает и по SSH
```

## Установка в систему (ярлык и иконки)

Иконки приложения лежат в `icons/<размер>/dns-manager.png` и предназначены
для размещения в стандартной теме hicolor:

```
# for s in 32x32 64x64 128x128 256x256; do
    install -Dm644 icons/$s/dns-manager.png \
        /usr/share/icons/hicolor/$s/apps/dns-manager.png
  done
# install -Dm755 dns-manager.py /usr/share/dns-manager/dns-manager.py
# cp -r dnsmgr /usr/share/dns-manager/
# install -Dm644 dns-manager.desktop /usr/share/applications/dns-manager.desktop
# gtk-update-icon-cache /usr/share/icons/hicolor 2>/dev/null || true
```

В `dns-manager.desktop` указан путь `Exec=/usr/share/dns-manager/dns-manager.py` —
поправьте, если размещаете программу в другом каталоге.
